## 🛠️ Implementation / Content

- Progress: 완료.
- 설계 결정:
  - **저장 위치**: `~/.cache/workflow_kit/registry.json` (host-scoped).
    `WORKFLOW_REGISTRY_PATH` env 1개로 override. `XDG_CACHE_HOME` 도 honor.
  - **스키마**: `{schema_version: "1", host_id: str, updated_at: iso, entries:
    [{path, branch, harness, endpoint, registered_at, last_seen_at}]}`.
  - **write**: atomic (tmp + os.replace). 권한 0o600.
  - **`host_id`**: `WORKFLOW_HOST_ID` env > `hostname` > `uuid.uuid4().hex[:8]`.
  - **register**: 동일 path 가 있으면 `last_seen_at` 만 갱신 (no-op + UPDATE).
  - **unregister**: `--path` 또는 `--branch`. `--all` 로 전체 청소 (테스트 안정성).
  - **`paths()`**: registry 의 모든 `path` 를 list[Path]. dashboard 가 *합류시킬
    후보* 로 사용.
  - **stale**: `last_seen_at` 이 7일 초과면 report 만. 자동 삭제 ❌ (사용자 확인 §5D.4).
  - **dashboard 연동**: `collect_recent_releases` 가 `extra_roots=None` 일 때
    registry paths 를 *추가로* 합류 (auto + env + registry). registry 부재 → 기존
    100% 호환.
  - **도구**: `tools/workspace_registry.py` — `register -p <path> [-b -H -e]`,
    `unregister --path <p>|--branch <b>|--all`, `list`, `paths`. `--dry-run` 기본,
    `--apply` 로 실제 변경. `--json` 출력.

  - cross-host 동기화 (단일 호스트 file 만).
  - TTL 자동 비활성 (표시만).
  - server-side push 중재.
