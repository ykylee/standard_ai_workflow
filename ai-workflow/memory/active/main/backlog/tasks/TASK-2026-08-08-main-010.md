## 🛠️ Implementation / Content

- 진행 현황: 완료.
- 설계 결정:
  - **frozen dataclass + default factory**: `env: dict[str, str] = field(default_factory=dict)`.
    `dataclasses.replace` 로 새 entry 만들 때 env 도 같이 갈 수 있다. read-only
    `__hash__` 는 `frozen=True` 가 보장.
  - **하위 호환 load**: `RegistryEntry.from_dict` 가 `d.get("env", {})` 사용. field
    누락 → `{}` 자동.
  - **JSON 직렬화**: `to_dict` 가 `env` 도 dump. round-trip 정상.
  - **register()**: `env` kwarg 받음. *현재 entry 가 이미 있으면* `replace` 로 env 만
    갱신 (idempotency + env override).
  - **seed env 자동**: seed 가 `REPO_ROOT` 와 `PYTHONPATH` 를 *현재 도구가 설치된*
    프로젝트 context 에서 자동 계산. (도구가 어느 프로젝트의 작업자인지 알 수 있는
    단서 = `__file__.resolve().parents[2]` 의 결과.) 표준 §6.5.2 형식 그대로.
  - **sync_mavis env**: `entries.env` 가 dict 이고 비어있지 않으면 그 dict 를
    `mavis:<branch>` alias env 로 emit. 비어있으면 env 키 자체 생략.
  - **공백/None guard**: env 값의 key/value 가 빈 문자열 / None 이면 skip.

- 비범위:
  - 다른 entry (harness / endpoint) 의 env 자동 합성 (다음 사이클).
  - cross-host registry sync (cross-host 가설).
