  block 에 `command=None` 만 emit — 그게 곧 mavis 가 *실행할 명령* 이 없으니

  endpoint 가 `cmd:/abs/tool` 형식이면 mavis alias block 에 `command` 와 `args`

  *알림* 역할). 그 외 형식은 그대로 alias 의 endpoint 필드에 (mavis 가 이해 못
  함 — caller 책임).

- 완료 기준: (1) endpoint="cmd:/abs/tool" → alias.command=tool, args=[]. (2)
  endpoint="url:http://..." → alias.url, type=streamable-http. (3) endpoint=None
  → command/url 둘 다 없음. (4) 그 외 형식 → alias.endpoint 보존. (5) sync_mavis
  가 위 4가지 모두 PASS. (6) 회귀 5+ assertions. (7) 전체 회귀 15+ green.

## 🛠️ Implementation / Content

- 진행 현황: 완료.
- 설계 결정:
  - **합성 규칙**:
    - `"cmd:<path>"` prefix → `{"command": <path>, "args": []}`. (향후 args 자동
      합성 가능; 이번 task 범위 밖.)
    - `"url:<url>"` prefix → `{"url": <url>, "type": "streamable-http"}`. (mavis
      글로벌의 http alias 표준 형식, §6.5.2 builtin 5종 패턴 정합.)
    - `None` → command/url 둘 다 *생략* (alias 가 메타만 — `enabled` /
      `configured` / `description`).
    - 그 외 → `endpoint` 라는 key 에 그대로 보존. (mavis 가 이해 못 할 수 있어
      caller 책임 — *advisory* 메타.)
  - **단일 함수**: `_endpoint_to_mavis_fields(endpoint) -> dict` 가 위 4가지 모두
    처리. sync_mavis 와 export_to_mavis 가 같은 함수를 사용 (정합).
  - **순서**: `command` / `args` / `url` / `type` (있는 것만) → 그 외 `endpoint`
    fallback.
  - **endpoint parse 실패 시 silent skip**: prefix 매칭이 안 되는 경우 raw value
    를 *그대로* `endpoint` 필드에 박는다. mavis 가 모르는 형식이라도 registry 가
    보존한다 (advisory).

- 비범위:

  - endpoint 의 *dynamic discovery* (호스트 위에서 probe) — 별도 task.
