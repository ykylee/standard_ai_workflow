- 작업 내용: TASK-015 의 federation *merge API* 를 *읽기* 경로로 마무리. known_hosts 의
  endpoint (`http://` / `file://`) 를 따라가서 *원격 호스트의 registry* 를 fetch 한 뒤
  local 과 `merge_entries()` 로 합친다. dashboard 가 federation view 를 자동으로 보여주게.

- 완료 기준:
  1. `workspace_registry.pull_remote_registry(host_id) -> dict` — urllib 로 GET,
     response 가 registry JSON 형식이면 dict (raw registry), 아니면 `{"error": ...}`.
     timeout / unreachable / malformed 모두 graceful skip.
  2. `workspace_registry.pull_all_remote_registries() -> list[(host_id, result)]` —
     모든 known hosts 순회. 실패한 host 는 `("hostX", {"error": ...})`.
  3. `workspace_registry.merge_with_remotes(local_entries) -> tuple[list[RegistryEntry], list[dict]]`
     — local + pull 결과 (raw registries) 를 `merge_entries()` 로 합치고, errors 도 emit.
  4. **Remote cache** `~/.cache/workflow_kit/remote_cache/<host_id>.json` (atomic, 0o600,
     TTL 1h). HTTP pull 실패 시 cache fallback (graceful).
  5. `tools/host_pull_registry.py` CLI: `pull --host <id>` / `pull --all` / `--apply` (default dry-run) / `--json`.
  6. `dashboard_data._registry_extra_roots` 가 `merge_with_remotes()` 호출 (timeout 2s, cache fallback).
     기존 local paths + remote entries 의 path 둘 다 합류.
  7. smoke `check_host_pull.py` (stdlib only) ALL PASS — 6+ case: local http.server in thread (실제 HTTP pull), unreachable host (offline port), malformed JSON, cache fallback, merge 후 source_host_id 보존, timeout.

  - **stdlib only** (`urllib.request` + `json` + `socket` + `tempfile`).
  - **No retries** — pull 1회, 실패 시 cache fallback. retry 는 운영자 판단 (스펙 외).

  - **Cache TTL 1h** — `WORKFLOW_CACHE_TTL_SECONDS` env override.
  - **HTTP only** for endpoint fetch (TLS ❌, 인증 ❌). `file://` 도 지원 (test only,
    운영자가 sshfs mount 가정). §7.4 의 "인증 / TLS / mutual TLS 는 현재 scope 밖" 정합.
  - **Pull on dashboard call** (no in-process polling). 비용 < 2s/호출 × N known hosts.
  - **`merge_with_remotes()` 가 *winning entries* 만 반환** — local 포함 dedup 결과.
    errors 는 별도 emit (caller 가 *panel 5 extra meta* 로 표시 가능).
