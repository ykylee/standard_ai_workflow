- 결정 사항 (사용자 채택, 2026-08-08 22:55 KST):
  - **3-way drift enum**: `planned_done` / `planned_undone` / `unplanned_done`. ID
    기준 (TASK-xxx pattern), *title* drift 는 v2 (의미 분석 필요).
  - **Pre source**: pre handoff 의 *다음에 할 일 (순서)* 섹션. 사용자가 `--pre-handoff <path>`
    또는 `--pre-commit <hash>:<path>` (default = `git show origin/main:<path>`) 으로 제공.
  - **Post sources**: (a) post handoff 의 *최근 완료 작업* 섹션, (b) `git log <range>`
    의 commit message. 두 source 의 *합집합* = done. (둘 중 하나만 있어도 OK.)
  - **Drift score (advisory)**: `|unplanned_done| + |planned_undone| / max(|planned|, 1)`.
    0 = clean, 0~0.3 = minor, 0.3~0.7 = significant, 0.7+ = major. *advisory only* —
    사람 판단 영역.
  - **No auto-block** — `--exit-on-drift` flag 가 명시되어야만 non-zero exit. §5D.4
    정합 (되돌릴 수 없는 결정은 사람).
  - **Pure function** — CLI 는 thin wrapper, `drift_detection.detect_scope_drift()` 가
    핵심. smoke 가 subprocess 없이도 unit test 가능.
