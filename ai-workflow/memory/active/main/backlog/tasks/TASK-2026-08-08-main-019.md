- Description: §0.8 #4 "`--force` 서버측 (branch protection) 이중화" 의 client-side 보강.
  §5D.4 가 도구 level 에서 `--force` option 을 *제공하지 않음* (이미 구현). 그러나 *사람* 이
  `git push --force` 를 직접 실행하면 도구 우회. → pre-push hook 으로 client-side
  이중화. hook 은 *모든* `git push` 호출에서 `--force` / `-f` / `--force-with-lease` flag
  를 감지 → non-zero exit 으로 거부.

- Completion criteria:
  1. `tools/hooks/pre-push-no-force.sh` — `--force` / `-f` / `--force-with-lease` 감지 시 `exit 1` + stderr 메시지. POSIX `sh` (bash 의존 ❌). 기존 hook 있으면 backup 후 교체, 없으면 신규 작성. idempotent install.
  2. `tools/install_pre_push_hook.py` — `install` / `uninstall` / `status` 3개 sub-command. `--dry-run` (default) / `--apply`. backup 자동 (`pre-push.bak.<timestamp>`).
  3. `tools/install_pre_push_hook.py status` — hook 설치 여부 + 내용 hash + backup list.
  4. smoke `check_pre_push_hook.py` (stdlib only) ALL PASS — 6+ case: install fresh / install idempotent / uninstall / refuse `--force` / refuse `-f` / allow normal push / status report.
  5. `multi_workspace_orchestration.md` §0.7 적용 상태 + §0.8 #4 close + §5D.5 *이중화 정공법* section 신설 (client-side hook + server-side branch protection 가이드 + 1차 출처).
