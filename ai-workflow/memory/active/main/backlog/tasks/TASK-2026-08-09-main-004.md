## 🛠️ Implementation / Content

layer 2 (pre-push hook) 는 **로컬 설치형** 이라 hook 을 안 깐 호스트는 그대로
통과한다. 그 구멍이 서버측 branch protection 인데 *가이드* 로만 있었다 — 가이드는
지켜졌는지 아무도 확인하지 않으니 실질적으로 layer 가 둘뿐이었다.

- 판정은 pure function (`evaluate_protection`) 으로 분리 — gh 없이 fixture 로 전부
  검사할 수 있다. 실제 GitHub 응답에 의존하는 검사는 네트워크/권한에 흔들려 회귀
  검사로 못 쓴다.
- **보호를 켜지 않는다.** 저장소 소유자의 결정이고 도구가 조용히 바꿀 설정이 아니다 (§5D.4).
- **필드를 못 읽으면 통과로 치지 않는다** — 권한 부족의 `null` 과 실제로 꺼진 것을
  섞으면 검사가 거짓 안심을 준다.
- gh 부재/미인증은 graceful skip (rc 0). *모름* 과 *없음* 은 다르다. 구분이 필요하면 `--require-gh`.
