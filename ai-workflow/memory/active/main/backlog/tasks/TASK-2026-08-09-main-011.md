## 🛠️ Implementation / Content

TASK-010 에서 P0-2 를 닫으면서 **acceptance 자체가 약하다** 는 걸 적었다:
"by_source 에 4 source 등장" 은 각 경로를 한 번씩만 돌려도 찬다. 실제로 그날 내가
한 일이 정확히 그 한 번씩이었다. 숫자는 찼지만 *지속적 사용* 은 재지 못했다.

**윈도 지표를 additive 로 얹었다** — 전체 기간 필드는 그대로 둔다 (기존 소비자 정합):

| 필드 | 뜻 |
| --- | --- |
| `window_days` | 윈도 크기(일). 기본 30. `0` 이면 윈도 집계 생략 |
| `window_calls` / `window_hits` / `window_hit_rate` | 윈도 안 집계 |
| `window_by_source` | 윈도 안 source 별 {calls, hits} |
| `window_source_count` | **AC2 의 실질 지표** — 윈도 안 distinct source 수 |

`summarize_telemetry(ws, window_days=30, now=None)`. `now` 는 테스트 주입용이다
(시간 의존 검사를 재현 가능하게).

CLI: `--command=memory-index-telemetry --window-days=N`. 기본 출력에 윈도 블록 추가.

**naive timestamp 방어**: 과거 event 가 tz 없이 들어와 있으면 `<` 비교가
`TypeError` 로 터진다. UTC 로 간주해 넘긴다 — 집계가 예외로 죽는 것보다 낫다.
