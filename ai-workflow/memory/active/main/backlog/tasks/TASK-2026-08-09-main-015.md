- 커밋 메시지에 그 흔적이 있다 — `... (전량 205/205)`, `... (전량 206/206)`.

  갱신을 모르고** 한 오독이었다. `git show v1.0.0-beta:...` 로 보면 **199/199**
  로 정합했다.)

태그 시점 대조 실측:

| 태그 | 실제 파일 | 노트 |
