## 🛠️ Implementation / Content

**만성 실패의 뿌리는 셋 다 "게이트가 실제를 재지 않는" 부류였다:**

1. **doctor — 경로가 두 겹으로 틀려 있었다.** `cmd_validate` 가
   `--project-root REPO_ROOT`(= `workflow-source/`) 를 넘기는데 baselines 는
   `project_root/"workflow-source"/tests` 를 조립한다 → `workflow-source/workflow-source/`
   를 탐색해 **0 files 를 재고 non_compliant** 를 냈다 (`across 0 files` — 아무것도
   안 잰 검사가 실패를 보고). 수정: `--project-root REPO_ROOT.parent` +
   `--config-path REPO_ROOT` (config 는 `workflow-source/pyproject.toml` 에 있으므로
   명시 — silent default fallback 방지, §2.49). 추가로 doctor subprocess 가 caller 의
   PYTHONPATH 상속에 암묵 의존하던 것을 env 명시로 교체.
2. **doctor — 경로를 고쳐도 TST-WF-01 이 만성 red.** `min(def test_/case_ count) ≥ 5`
   판정이 이 저장소 smoke 의 정당한 관행 2종 (inline `check(label, cond)` /
   `failures.append` 수집식) 을 못 본다 — 실제 case 는 있는데 이름 count 0. 전례
   (v0.15.18 의 `assert True` dummy wrapper 575개) 는 가짜 측정이라 답습하지 않고,
   `[tool.workflow-doctor] partial_rules.testing = [TST-WF-02..06]` 으로 **선언된
   예외** 처리 (이유를 config 주석 + stable_guarantee §5.1 에 기록). TST-WF-01 은
   advisory 로 계속 보고된다.
3. **state — reader 만 legacy 에 남은 죽은 계약.** `memory.last_freeze` 의 writer 는
   v0.7.x raw-mirror 전용 도구(`refresh_wiki_memory.update_state_json`)뿐이고 현재
   정본 writer (`generate_workflow_state.py`, branch-scoped) 는 그 섹션을 안 쓴다
   ([[state-json-silent-failing]] 과 같은 모양). 판정을 현 계약 top-level
   `generated_at` 로 교체 (legacy `last_freeze` 는 하위호환 인정, parse 실패는 fail).
4. **release 기본값 APPLY → dry-run.** `--apply` argparse default True 가 main() 의
   "둘 다 없으면 dry-run" 정규화를 무력화하고 있었다. default False 로 반전 +
   `cmd_release` 진입 시 `apply 아니면 dry_run=True` 보강 (in-process caller 방어,
   `--dry-run --apply` 는 dry-run 승). `wk release-create` wrapper / lib 은 이미
   dry-run 기본이라 세 진입 경로가 이제 정합.
5. **개별 skip 플래그.** `release` 에 `--skip-packaging/-doctor/-state/-git/-mypy`
   신설 — 이전엔 `--skip-validate` 뿐이라 게이트 하나를 건너뛰려면 전부를 꺼야 했다.
6. **mypy 게이트 출처 구분.** `-m mypy` 는 모듈 부재 시 FileNotFoundError 가 아니라
   rc 1 + stderr 로 죽어 기존 except 분기가 영원히 안 탔다 — "오류 발견"과 "실행
   불가"가 같은 모양(ok False, error_count 0)이었다. 판정은 fail 유지, `error` 로
   출처만 구분.

**회귀 고정**: `check_release_pre_check_gates.py` 10/10 신설 — argparse default (AST) /
무인자 dry-run (subprocess) / dry-run 승 / doctor argv (AST) / baselines 가 실제
파일 ≥100 을 재는지 / doctor·state functional / **결함 되주입** (generated_at 없는
state → fail) / legacy 하위호환 / partial 선언 고정 (조용히 지워지면 잡힘).
