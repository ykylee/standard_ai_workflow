  기계 판독 필드는 그때 정합시켰으나 **어느 쪽이 정본인지는 여전히 미선언**이라,

  state.json 의 `recent_done_items` 도 같은 상한으로 잘린다." 그 선언을 문서와
  절차와 검사에 반영한다.

- **드리프트가 쌓인 진짜 원인**: 세션 종료 절차에 생성기를 부르는 단계가 **없다**.
  `refresh-purpose --apply` 는 `purpose_digest` 만 건드리고, 전체 재생성은
  `generate_workflow_state.py` 스크립트뿐인데 아무도 호출하지 않는다. 선언만 하고
  절차를 안 고치면 드리프트는 그대로 쌓인다.

- 완료 기준:
  1. `state.json` 이 생성물임이 문서에 **명시**된다 (손 편집 금지 + 재생성 명령).
  2. 세션 종료 절차에 생성기 호출이 들어간다.
  3. `state.json` 이 생성기 출력과 갈라지면 **검사가 잡는다** (되주입으로 실증).
  4. **handoff 형식이 생성기 입력**이라는 사실이 문서화된다 — 이게 없으면 handoff 를
     자유롭게 쓰는 순간 state.json 이 조용히 다시 오염된다 (TASK-017 §2 실측).
  5. 전량 2축 green.
