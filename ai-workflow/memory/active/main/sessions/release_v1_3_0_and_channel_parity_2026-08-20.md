## 0. 한 줄 요약

**v1.3.0 을 발행했고, 그 과정에서 같은 모양의 결함을 여섯 번 더 만났다.**

반복된 것은 하나다 — **검사·지표·탐침이 "있는가" 를 재고 "무엇을/몇 개를" 을
안 잰다.** 이 세션의 내용은 그 반복을 매번 다른 자리에서 잡은 기록이다.

## 2. v1.3.0 — `!` 는 무엇에 대한 breaking 인가

101 커밋(feat 17 · fix 24 · breaking 1)을 **minor** 로 끊었다. `feat(okf)!` 가
있었지만 그 `!` 가 가리킨 것은 **외부 OKF spec 의 버전**이지 우리 API 가 아니다:

1. 공개 Python API 시그니처 변경 0
2. 은퇴한 진입점 2종은 **남아서 rc=0** — 옛 인자도 계속 받는다
3. 번들이 legacy 형태를 유지해 v0.1 소비자도 그대로 읽는다
4. SPEC §13 자신이 v0.2 를 *"a minor version bump"* 로 규정한다

판단 기준을 `docs/RELEASE.md` **§1.5** 에 4문항으로 정본화했다 — 기준이 없으면
같은 모양의 커밋에서 매번 다시 헤맨다. 도구는 근거를 모아 `requires_decision`
으로 사람에게 넘기고, 사람은 이 절을 보고 판단한다.

태그에서 `-beta` 가 빠진 첫 릴리스다 (§2.2 규약이 v1.2.1 부터 정리돼 있었는데
노트만 옛 표기였다).

## 3. 관찰 축 — 관찰이 지표가 아니라 배선을 찾아냈다

- **mypy flake**: 원인 계열 확정 — race 가 아니라 **mypy INTERNAL ERROR**.
  근거는 아티팩트의 `stderr_tail` 원문과 `duration 0.65s` (정상 3.4s/197파일)
  — 분석 중이 아니라 **시작 단계**에서 죽었다. 4번 터지도록 못 좁힌 이유는
  **증거가 로그까지 못 온 것**이었다(요약 120자 + excerpt 400자 절단). 완료
  기준을 "N run 연속 green" 에서 **"다음 재발이 트레이스백을 남긴다"** 로 개정.
- **memory_index 3-tuple**: `distinct_entries_retrieved` **1/9**. 8/10 회고가
  미리 적어 둔 판정 조건에 걸렸다. 원인은 검색이 아니라 **배선** — 종료 절차
  `wk suggest-memory-entries` 가 정본·CLAUDE.md·AGENTS.md 어디에도 없어
  (grep 0건) 한 번도 안 돌았다. 정본 §8.1·§11.1 에 넣고 같은 세션에 실제로
  돌려 2건 승격. `entries_total` 9 → **11**, `entries_new_30d` 2 → **4**.
- **cross-host federation**: 두 번째 호스트가 없어 **원리적으로 못 잰다**.
  관찰이 아니라 대기다 — 그렇게 적었다.

## 4. 채널 파리티 — 광고와 배선이 어긋나 있었다

사용자가 만든 `session-end` 스킬이 안 쓰이던 문제. 플러그인 채널은 처음부터
4종인데 bootstrap 채널(`.claude/commands/`)은 3종만 emit 했다 — 생성기
docstring 이 스스로 "3 slash command" 라 적고 있었다. 그런데 진입 스킬의
`description` 은 **이미 세션 종료를 약속**하고 있었다. 광고가 4단계인데 배선이
3개면 모델은 있지도 않은 명령을 찾는다.

**남은 절반**: 플러그인 스킬 4종이 인벤토리엔 있고 세션엔 없다. 가설 4개를
실측으로 기각했다(파일 부재 · 비활성 · 매니페스트 파손 · **설치가 세션보다
21시간 앞선다**). 확정된 사실 하나 — `claude plugin details` 는 `Skills (4)` 로
다 세는데 호출하면 `Unknown skill` 이다.

## 5. 이 세션이 남긴 규칙

- **인벤토리는 가용성의 증거가 아니다.** 설치·활성화·파일 실재·인벤토리를 전부
  통과하고도 못 쓴다. 마지막 한 칸은 **실제 호출**로만 재진다.
- **지표의 분모는 '찾은 것' 이 아니라 '선언한 것' 이다.** 아니면 대상을 지울수록
  점수가 올라간다.
- **검사가 '불일치' 를 외치기 전에 자기가 무엇과 비교하는지 확인한다.** 두 값이
  서로 다른 범위를 재고 있으면 불일치는 결함이 아니라 **검사의 오답**이다.
- **판정을 복제하지 말고 생성기와 같은 함수를 부른다.**
- **증거는 만들어 두는 것으로 부족하고 소비 지점까지 도달해야 한다.** 그리고
  **신호가 앞에 와야** 한다 — 보일러플레이트로 시작하는 메시지는 잘리면 잡음만 남는다.
- **버전을 올리는 일은 생산 형식만의 문제가 아니다.** 소비 정책을 같이 보지
  않았다면 OKF v0.2 이행이 유일하게 실측된 상호운용을 조용히 끊었을 것이다.
- **도달 불가능한 분기는 검사되지 않은 분기다.**
- **손으로 푸는 일이 2세션 반복되면 도구 결함이다.**
