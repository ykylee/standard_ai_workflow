# 미등록 하네스 제보·검토·등록 요구사항

- 문서 목적: 세션 클라이언트가 아직 허브에 없는 하네스 정보를 전달하고, 검토된 정보만 허브 레지스트리에 등록하는 흐름을 정의한다.
- 범위: 세션 판정, 제보 필드·검증, admin 웹 승인, 별도 사람 명부, 전역 메타데이터 등록, 런타임 parity.
- 대상 독자: 허브 사용자, 클라이언트 작성자, 운영자, 구현자.
- 상태: 구현 진행 (M-060/WBS-60.1)
- 최종 수정일: 2026-11-24
- 관련 문서: [허브 레지스트리 계약](../../workflow-source/core/hub_harness_registry_spec.md), [운영 안내](../HUB_OPERATIONS.md)
- 요청: TASK-2026-11-24-main-003

## 목표 흐름

1. 클라이언트는 `hub_session_start(session.harness=...)`로 현재 하네스를 알리고,
   응답의 `hub.harness_support.status`에서 `unknown` 여부를 확인한다.
2. 클라이언트는 별도 MCP 도구로 제한된 하네스 프로필과 근거를 제보한다.
3. 제보는 `pending`으로 저장되고, 기존 지원 목록·셋업 계획·다른 프로젝트 설정에는 영향을 주지 않는다.
4. 허브 관리자가 웹 화면에서 제보를 읽고 승인하거나 이유를 남겨 거절한다.
   최초 등록 승인은 별도 사람 명부에 등록된 담당자 한 명 이상을 지정해야 한다.
5. 승인된 프로필은 허브 전역 메타데이터 레지스트리에 포함된다. 개별 adapter 구현이
   완료되지 않은 하네스는 셋업 지원으로 표시하지 않는다.

## 제출 정보

제보에는 정규화된 하네스 ID, 표시 이름, 버전, OS/플랫폼, MCP transport 및 설정 형식,
설정/진입 파일 후보, 공식 문서 URL, 짧은 검증 메모를 담는다. 임의 환경 변수,
전체 파일 내용, 실행 로그, 사용자 홈 절대 경로, 명령어 인자, 인증 정보는 받지 않는다.
허브는 중첩 객체와 문자열 값에 secret scan을 적용하고, 식별자·길이·URL·경로 형식을
검증한다.

## 권한과 상태

- 프로젝트 콜사인 토큰: 제보 제출, 자신의 프로젝트에서 제보 상태 조회, 승인 레지스트리 읽기.
- hub admin 토큰: 웹 화면에서 전역 대기열 조회, 별도 사람 명부 관리, 담당자를 지정해 승인·거절한다.
- 사람 담당자는 하네스 제보와 독립해 허브 사람 명부에 등록된다. 하네스 하나에는 여러 사람이
  지정될 수 있다. 이 명부는 연락·책임자 메타데이터이며 로그인 계정이나 권한 주체가 아니다.
- MCP에는 사람의 승인 도구를 제공하지 않는다. 에이전트는 `hub_harness_report`로 요청만 올린다.
- 상태 전이: `pending -> approved | rejected`; 승인 이후 수정은 새 제보/registry 새 판으로 기록한다.
- 각 제보는 프로젝트 ID, 제출 콜사인, 시각, 클라이언트 버전을 보존한다. 승인/거절 actor와
  시각, 결정 메모도 append-only event에 기록한다.
- 등록 승인은 메타데이터 검토다. adapter 레시피는 별도 구현·검증 과정을 거친다.

## 승인 및 실제 지원

허브는 승인된 이름과 메타데이터를 전역 레지스트리에서 재사용할 수 있게 한다. 자동
셋업은 현재 built-in adapter만 지원한다. 등록 메타데이터만으로 `hub_setup_plan` 지원이
확장되지 않으며 등록부 응답은 `setup_ready=false`를 명시한다.

## 수용 기준

- 미등록 세션은 사용자가 제보할 수 있는 MCP 경로와 필요한 정보 목록을 알 수 있다.
- 제보 저장은 기존 registry 및 setup 결과를 바꾸지 않는다.
- 사람은 admin 웹 화면에서만 승인할 수 있고, web/callsign 토큰의 전역 승인 시도는 거부되며
  승인/거절에 provenance와 audit event가 남는다.
- 최초 승인 시 독립된 사람 명부에서 한 명 이상을 지정해야 하며, 등록부 조회에 담당자가 표시된다.
- 승인 프로필과 setup 지원 여부를 구분해서 노출하고, 미검증 하네스는 기존 셋업 도구가
  지원하는 것처럼 처리하지 않는다.
- Python과 Go 구현의 DB·MCP·HTTP 의미 및 오류 계약이 일치한다.
