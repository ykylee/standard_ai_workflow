## 0. 릴리스 판정

이 사이클의 주제는 **"선택 실행의 실패 모드는 느려지는 것이 아니라 조용히 안
도는 것"** 이다. `--changed`(v1.4.0, main-003) 의 `WATCHES` 선언이 실제 입력
표면과 맞는지 재는 수단이 없었고, 첫 실측(discovery 전량 1축)이 그 침묵의
크기를 보였다: **선언 8개 중 7개가 좁은 선언**이었다. 특히 release 계열 2개는
저장소 전체(실측 1159·1185 경로)를 읽으면서 memory 변경 시 skip 되고 있었다 —
로컬 green + CI red 를 만드는 바로 그 모양이 선택 실행 안에 잠복해 있었다.

**게이트는 축소하지 않는다** (requirements R0 — main-004 기각의 재확인).
meta-watch 는 게이트를 좁히는 수단이 아니라, 편집 루프의 선택이 거짓말하지
않게 만드는 수단이다.
