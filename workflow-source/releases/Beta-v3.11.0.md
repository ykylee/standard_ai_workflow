## 변경

- **결정 탭 — 사람이 승인할 것을 한 큐로**: 확인 요청 · 세션 승인 · 열린 DCR · 열린 지침 제안이 탭 넷에 흩어져 있었다. '결정' 탭 한 화면에 같은 카드(종류 꼬리표 · 누가 무엇을 · 때 · 근거 · 결정 메모 폼)와 같은 승인 문법으로 모은다. 탭에 대기 건수가 붙고, 개요의 '승인할 것' 칸은 결정 탭의 그 묶음으로 간다. 지침 제안도 같은 폼이다(메모 칸 없음).
- **탭 아홉 → 다섯**: 개요 · 결정 · 오케스트레이션 · 로드맵 · 더 보기(아이디어 · 지식 · 지침 · 이력 · 결정 변경 기록 · 확인 요청 기록). 예전 주소는 그대로 열린다. task 상세에도 탭이 붙었다.
- **휴대폰 — 오른손 엄지**: 좁은 폭에서 탭은 화면 아래 고정 막대(5칸 · 56px), 더 보기는 오른쪽 끝에서 위로 연다. 결정 단추는 거절 왼쪽 · 승인 오른쪽(넓게)이고, 카드를 스크롤하는 동안 탭 막대 바로 위에 붙어 있다. 단추 · 입력 높이 44px 이상.
- **승인 카드 주어는 콜사인**: 3.9.2 부터 세션 승인 카드가 'S-… 가 pc 에서 …' 로 나오던 회귀를 고쳤다(요청자 칸은 세션 ID). 오케스트레이션 제목 · 탭은 늘 맨 위, 좁은 폭에서 한국어를 어절로 꺾고 표가 쌓인다.
- **워크벤치는 허브로 옮긴 저장소에서 읽기 전용**: 응답 · 할 일 쓰기 대신 '허브에서 답한다' 링크, 서버도 409. 상태는 한국어, 4px 강조 띠 제거, 제목 위계 · 포커스 표시.
- **표준 블록 2.5**: 도구 카탈로그(이름 91개)를 묶음 접두사로 줄여 표준 블록 7,609 → 5,062B, 빈 지침 렌더 5,369B — 프로젝트 지침 자리가 약 2.8KB 생겼다(예산 8KB). 모든 도구는 이름이나 접두사로 진입 파일에서 찾을 수 있다(검사 유지). 각 저장소의 진입 렌더 영역이 다음 렌더에 바뀐다.
