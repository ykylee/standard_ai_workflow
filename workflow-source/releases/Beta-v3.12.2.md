# Beta v3.12.2 — 넓은 화면 진척 띠 · 탭 사이 흔들림 · 해요체 (2026-11-27)

> **상태: 실환경 pilot용 pre-release.** GitHub Release는 prerelease로 표시하고 안정판 latest는 v2.1.0에 둔다.

## 변경

### 허브 화면 배치

- **넓은 화면 진척 띠 넘침**: 띠를 담은 grid 칸의 최소 폭이 내용 폭(auto)이라, 줄바꿈 없는 긴 마일스톤 이름만큼 띠가 늘어 화면 밖으로 넘쳤다(운영 허브 1280px 에서 1,770px · 가로 578px 넘침). 칸이 0 까지 줄게 했다. 좁은 폭은 이름을 숨겨 안 보였고, 화면 검사 fixture 는 이름이 짧아 못 봤다 — fixture 이름을 운영 길이로 늘리고 넓은 폭(1280 · 1920)도 잰다.
- **탭 사이 흔들림**: 개요만 제목과 탭 사이에 프로젝트 정보 줄이 있어 탭 막대가 44px 아래였고, 짧은 화면(세로 스크롤바 없음)은 본문이 옆으로 7px 움직였다. 프로젝트 정보 줄을 탭 아래로 옮기고 `scrollbar-gutter: stable` 로 스크롤바 자리를 늘 둔다. 일곱 탭에서 제목 · 탭 막대 자리가 같다.

### 해요체

- 허브 · PC 중계 화면 문구의 반말 종결을 해요체로(손으로 만든 낱말 표 117개 — 불규칙 활용 때문에 규칙 변환은 틀린다). 읽는 사람에게 하라는 문장은 `~해 주세요`, 확인창은 `~할까요?`.
- 화면에 뜨는 서버 오류 메시지(Python 허브 · Go 허브 652곳)도 같은 표로 — 두 구현의 문장이 같다. **`error_code` 는 그대로**이고 `message` 문장만 바뀐다. 오류 문장을 그대로 비교하는 바깥 도구가 있으면 `error_code` 로 바꾼다.
- 그대로 둔 것: A2A 프로토콜 오류(에이전트에게 가는 응답) · 1.x 판정 함수(Go `judge` · Python `workflow_kit.judgecli`, 두 쪽 출력 대조).
- 새 검사 `check_screen_copy_register` — 화면 파일 · Go 사본 · 서버 메시지 자리에 반말 종결이 다시 들어오면 red.
