# Beta v3.2.3 — 프록시 뒤 계정 로그인 수리 (2026-11-24)

> **상태: 실환경 pilot용 pre-release.** GitHub Release는 prerelease로 표시하고 안정판 latest는 v2.1.0에 둔다.

## 변경

- 리버스 프록시가 Host를 바꾸거나 `X-Forwarded-Proto`를 넘기지 않으면 계정 등록·로그인·확인 요청 결정이 `403 origin_mismatch`로 막히던 결함을 고쳤다. 허브에 설정한 공개 주소(`--public-url`)를 출처로 인정한다.
- 공개 주소로 로그인한 세션 쿠키를 HTTPS면 `Secure`로, 하위 경로면 그 경로로 한정한다. 이전에는 같은 호스트의 다른 앱에도 쿠키가 전송될 수 있었다.
- 토큰 없이 허브 계정을 만들 수 있다. 가입만으로는 어떤 프로젝트도 열리지 않으며, 참여 요청 뒤 소유자가 승인한다. 실행 승인은 소유자만 한다. 토큰 없는 가입은 시간당 30건으로 제한한다.
- 계정 비밀번호 하한을 12자에서 8자로 낮췄다.

## 검증
