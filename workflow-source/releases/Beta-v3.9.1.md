# Beta v3.9.1 — 결정 두 묶음, 결정 메모 폼, 진척 띠 넘침 수리 (2026-11-26)

> **상태: 실환경 pilot용 pre-release.** GitHub Release는 prerelease로 표시하고 안정판 latest는 v2.1.0에 둔다.

## 변경

- **사람이 결정할 일 두 묶음**: 개요의 결정 칸을 '승인할 것'(확인 요청 · 중계 승인 · DCR · 지침 제안 — 승인하면 실행되거나 확정된다, 주황)과 '살펴볼 것'(열린 결정 task · 막힌 task, 무채색)으로 나눴다. 승인할 것이 먼저다. 머리줄 건수도 묶음별이다.
- **결정 메모 폼 하나**: 확인 요청 · 중계 승인 · DCR 이 같은 폼을 쓴다 — 꼬리표 달린 여러 줄 칸, 메모가 어디로 가는지 설명, 승인 / 거절. 보내는 동안 두 단추를 끄고(두 번 누름 방지) 자동 새로고침을 멈춘다. 확인 요청의 오류는 그 카드 안에 보이고 적던 메모가 남는다.
- **진척 띠 넘침 수리**: 마일스톤이 7개를 넘으면 끝난 것을 한 칸, 열린 것을 지금 것 포함 5칸 이하, 나머지를 한 칸으로 접는다. 운영 허브(마일스톤 62개)에서 띠가 휴대폰 화면 밖으로 넘치던 결함이다. 좁은 폭에서는 칸 이름을 숨긴다(지금 마일스톤은 설명 줄에 있다).
